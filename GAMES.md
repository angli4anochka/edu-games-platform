# Игровые механики EduGames Platform

## Обзор

Платформа включает 14 различных игровых механик, аналогичных Wordwall.net, но с улучшенной интерактивностью и образовательным фокусом.

## Реализованные компоненты

### ✅ 1. Викторина (Quiz)
**Файл**: `frontend/components/games/Quiz.tsx`

**Описание**: Классический тест с множественным выбором

**Особенности**:
- Перемешивание вариантов ответа
- Таймер на каждый вопрос
- Система баллов (10 баллов за правильный ответ)
- Streak (серия правильных ответов)
- Объяснения к вопросам
- Прогресс-бар
- Анимация правильных/неправильных ответов

**Использование**:
```tsx
<Quiz
  questions={[
    {
      id: 1,
      question: "Сколько планет в Солнечной системе?",
      answers: ["7", "8", "9", "10"],
      correctAnswer: 1,
      explanation: "В Солнечной системе 8 планет после исключения Плутона"
    }
  ]}
  timePerQuestion={30}
  onComplete={(result) => console.log(result)}
/>
```

### ✅ 2. Сопоставление пар (Match Pairs)
**Файл**: `frontend/components/games/MatchPairs.tsx`

**Описание**: Найди соответствия между элементами из двух колонок

**Особенности**:
- Две колонки с перемешанными элементами
- Визуальная обратная связь при выборе
- Счетчик попыток
- Подсчет точности
- Анимация совпадений
- Ограничение по времени

**Использование**:
```tsx
<MatchPairs
  pairs={[
    { id: 1, left: "Москва", right: "Россия" },
    { id: 2, left: "Париж", right: "Франция" },
  ]}
  timeLimit={180}
  onComplete={(result) => console.log(result)}
/>
```

### ✅ 3. Колесо фортуны (Random Wheel)
**Файл**: `frontend/components/games/RandomWheel.tsx`

**Описание**: Крути колесо для случайного выбора

**Особенности**:
- HTML5 Canvas анимация
- Плавное вращение с замедлением
- Настраиваемые цвета сегментов
- Анимация результата
- Красивая визуализация

**Использование**:
```tsx
<RandomWheel
  segments={[
    { id: 1, label: "Алиса", color: "#FF6B6B" },
    { id: 2, label: "Боб", color: "#4ECDC4" },
  ]}
  animationDuration={5000}
  onSelect={(segment) => console.log(segment)}
/>
```

### ✅ 4. Система UI компонентов
**Файл**: `frontend/components/ui/GameUI.tsx`

**Компоненты**:
- **Timer** - обратный отсчет с цветовой индикацией
- **ScoreDisplay** - счетчик баллов с анимацией
- **ProgressBar** - прогресс выполнения
- **LevelDisplay** - отображение уровня
- **AttemptsDisplay** - визуализация попыток
- **StreakDisplay** - серия правильных ответов

## Планируется реализовать

### 5. Сортировка по категориям (Categorize)
Drag-and-drop сортировка элементов по категориям

**Особенности**:
- До 5 категорий
- До 30 элементов
- Drag and drop интерфейс
- Визуальная обратная связь

### 6. Карточки (Flashcards)
Переворачивающиеся карточки для запоминания

**Особенности**:
- Автоматическое переворачивание
- Режим изучения
- Перемешивание
- Поддержка изображений

### 7. Анаграммы (Anagram)
Составь слово из перемешанных букв

**Особенности**:
- Уровни сложности
- Система подсказок
- Таймер
- Визуализация букв

### 8. Пропущенные слова (Missing Word)
Заполни пропуски в тексте

**Особенности**:
- Банк слов для выбора
- Drag and drop или клик
- Проверка правописания (опционально)

### 9. Правда/Ложь (True/False)
Быстрая проверка утверждений

**Особенности**:
- Быстрые раунды (15 сек на вопрос)
- Две большие кнопки
- Мгновенная обратная связь

### 10. Викторина с картинками (Image Quiz)
Выбери правильную картинку

**Особенности**:
- Сетка из 4 изображений
- Увеличение при наведении
- Поддержка различных форматов

### 11. Мемори (Memory)
Найди все пары карточек

**Особенности**:
- Настраиваемая сетка (4x4, 6x6)
- Счетчик ходов
- Таймер
- Поддержка изображений и текста

### 12. Поиск слов (Word Search)
Найди спрятанные слова в сетке

**Особенности**:
- Сетка 15x15
- Горизонтальные, вертикальные, диагональные слова
- Список слов для поиска
- Выделение найденных слов

### 13. Кроссворд (Crossword)
Классический кроссворд

**Особенности**:
- Автогенерация сетки
- Подсказки
- Проверка правильности
- Сохранение прогресса

### 14. Виселица (Hangman)
Отгадай слово, называя буквы

**Особенности**:
- 6 попыток
- Визуализация виселицы
- Категории слов
- Подсказки

## Общие возможности

### Система баллов
- **Quiz**: 10 баллов за правильный ответ
- **Match Pairs**: 10 баллов за каждую пару
- **Streak бонусы**: дополнительные баллы за серии
- **Штрафы**: за неправильные ответы (опционально)

### Таймеры
- Обратный отсчет
- Цветовая индикация (красный < 10 сек)
- Автозавершение при истечении времени
- Отслеживание общего времени

### Прогресс
- Прогресс-бары для всех игр
- Счетчики вопросов/пар
- Процент выполнения

### Обратная связь
- Визуальная (цвета, анимации)
- Звуковая (опционально)
- Текстовые объяснения
- Мгновенная реакция на действия

### Результаты
Каждая игра возвращает стандартизированный объект `GameResult`:
```typescript
interface GameResult {
  score: number;              // Набранные баллы
  completed: boolean;         // Завершено ли задание
  time_spent: number;         // Время в секундах
  details: {                  // Дополнительные детали
    [key: string]: any;
  };
}
```

## Best Practices

1. **Используй общие UI компоненты** - не создавай дубликаты
2. **Следуй интерфейсу GameResult** - стандартизированные результаты
3. **Добавляй анимации** - делают игру живой
4. **Тестируй на мобильных** - responsive дизайн обязателен
5. **Обрабатывай edge cases** - пустые массивы, истечение времени
6. **Добавляй accessibility** - ARIA labels, keyboard navigation
